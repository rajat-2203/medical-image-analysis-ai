# Medical Image Analysis AI

An educational machine learning project for medical image
classification using Python and deep learning.

## Project Goals

- Understand medical image datasets and labels.
- Build an image preprocessing pipeline.
- Implement and train a convolutional neural network.
- Evaluate model performance using appropriate metrics.
- Expose predictions through an API.
- Build a simple web interface for image uploads.

## Technology Stack

- Python
- PyTorch
- NumPy
- Matplotlib
- scikit-learn
- FastAPI
- React

## Safety Notice

This project is intended for education and research.
It is not a clinically validated diagnostic system and
must not be used to make medical decisions.
